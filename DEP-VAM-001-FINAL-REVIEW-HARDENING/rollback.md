# Rollback

## Trigger

The fence-aware parser rejects valid approved headings, or a new guard prevents
the authorized compatibility-only rollback on an exact clean main checkout.

## Reversible steps

Prepare a new strict rollback DEP and fresh L3 approval; supersede only this
hardening's test/rollback semantics in a bounded compensating commit. Preserve
this DEP and all earlier provenance. Rebind the gate audit-only.

## Data compatibility

No runtime, schema, database, or stored-memory compatibility impact exists.

## Post-rollback verification

Run focused VAM-001 tests, all strict VAM-001 DEPs, frozen Subject diff, diff
check, complete Local Green, hosted CI, and fresh independent review.
