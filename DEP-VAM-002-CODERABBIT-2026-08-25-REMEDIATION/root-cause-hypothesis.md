# Root Cause Hypothesis

## Hypothesis

The branch accumulated multiple remediation DEP records. Their individual
claims were useful at their original commits, but the current-head review
cannot infer which record is authoritative, and a few rollback instructions
did not pin every executable prerequisite.

## Supporting evidence

CodeRabbit identified fourteen concrete locations. The affected files are
evidence artifacts, DEP documentation, and rollback instructions; no finding
requires changing the approved VAM-002 runtime contract.

## Contradicting evidence

Immutable shareable artifacts cannot be regenerated byte-for-byte without
their local raw source. They are retained with their original hash, while this
successor DEP records a current run instead of fabricating historical raw data.

## Falsification test

The binding test fails until the canonical list, full commit references,
pinned commands, and current-proof statements all exist. It also fails if an
archived artifact is treated as fresh evidence.

## Conclusion

Confirmed. The smallest safe correction is an append-only current evidence
record plus precise rollback and reproduction instructions. No product code or
public API behavior changes.
