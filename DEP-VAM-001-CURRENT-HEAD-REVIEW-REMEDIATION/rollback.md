# Rollback

## Trigger

The two-parent assumption is invalid for the actual GitHub merge strategy, or
the exact evidence correction is shown false.

## Reversible steps

Use a new strict DEP and fresh L3 approval; prepare a bounded compensating
change, preserve all provenance, and rebind the gate audit-only.

## Data compatibility

No runtime, schema, database, or stored-memory change exists.

## Post-rollback verification

Run focused tests, all strict VAM-001 DEPs, frozen diff, complete Local Green,
hosted CI, and fresh independent review.
